# Sistema de Gerenciamento de Treinos

## Objetivo

O sistema de Gerenciamento de Treinos tem como objetivo permitir que usuários organizem seus treinos, cadastrem exercícios e registrem os treinos realizados.

## Principais funcionalidades

- Cadastro de exercícios;
- Organização de treinos;
- Registro de treinos concluídos;
- Consulta dos exercícios cadastrados;
- Acompanhamento do histórico de treinos.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
